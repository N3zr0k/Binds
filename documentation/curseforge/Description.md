### Which key casts that spell again?

**Binds** answers it right in the tooltip. Hover a spell, item or macro and see how you trigger it: by **keyboard**, **mouse** or **Blizzard click casting**. No more searching action bars, the macro window or the key bindings menu.

Binds only **reads** your bindings. It never changes key bindings, macros or action bars.

---

### What you get

| | |
| --- | --- |
| **One clean section** | A single Binds block per tooltip, never duplicated |
| **Three categories** | Keyboard, Mouse and Click Casting, each color-coded with its own icon |
| **Real combinations** | `SHIFT + 1`, `CTRL + MOUSE4` — a mouse button with a modifier stays *Mouse* |
| **All your sources** | Action bars, stance bar, macros and Blizzard click casting |
| **Always current** | Updates when bindings, macros, bars or your form change; no constant scanning |
| **Only when you want it** | Optional: show the section only while Shift, Ctrl or Alt is held |

### Quick access

Binds sits in **Titan Panel**, on the **minimap** and in the **addon compartment**.

- **Right-click:** Binds options
- **Shift + left-click:** click casting settings
- **Shift + right-click:** key bindings
- **Mouseover:** every click cast you have set up, with its spell

---

### Good to know

- **Lightweight:** no dependencies; only your Binds settings are saved, bindings are always read live.
- **Two clients:** WoW Retail and WoW Forever from one download. Features a client lacks are hidden instead of throwing errors.
- **Languages:** English, German, French.
- **For developers:** optional BugLab support with debug output and diagnostic probes.

### Commands

| Command | Action |
| --- | --- |
| `/binds` | Open options |
| `/binds minimap` | Show or hide the minimap button |
